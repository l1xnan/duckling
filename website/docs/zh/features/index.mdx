# 功能总览

- **数据浏览** — 基于 Canvas 渲染的结果网格，支持分页、隐藏列、转置、结果过滤与单元格值查看。详见[数据浏览](/features/data-browsing)。
- **SQL 编辑器** — 基于 Monaco，具备表/列感知的自动补全、运行 / 格式化 / `EXPLAIN`、SQL 书签与可选的按语句分割模式。详见 [SQL 编辑器](/features/sql-editor)。
- **SQL 模板变量** — 写入 Jinja2 风格 `{{ variable }}` 占位符，通过 `/* @vars */` YAML 块注释声明值，一键运行多值查询（笛卡尔积 → 多个结果标签页）。详见 [SQL 模板](/features/sql-templates/)。
- **透视表** — 通过行维 / 列维与度量（`count` / `sum` / `avg` / `min` / `max`）构建透视，提供高基数警告与复制 SQL 能力。
- **列画像** — 每列的统计数据：总数、空值比例、去重数、最大/最小值以及高频取值。
- **按列统计** — 单列的值分布，以表格加柱状图呈现。
- **值查看器** — 以原始 / JSON 形式查看单元格，并提供「计算」标签页对选中单元格做统计（最小/最大/均值……）并导出为 Markdown。
- **数据导出** — 将当前结果导出为 CSV / TSV / JSON / Parquet / XLSX，支持分隔符、表头与压缩选项。详见[导出](/features/export)。
- **侧边栏** — 数据库资源管理器、查询历史与收藏（置顶表 + 已保存 SQL），均支持搜索。详见[侧边栏](/features/sidebar)。
- **设置套件** — 外观与语言、SSH 配置、快捷键、SQL 格式化、导入导出选项以及应用内更新。详见[设置](/features/settings)。
- **键盘快捷键** — 分类快捷键浮层（`Mod+/`）与可重映射的快捷键设置页。
