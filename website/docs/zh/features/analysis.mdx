# 分析工具

## 透视表

通过**行维**、**列维**与**度量**（`count` / `sum` / `avg` / `min` / `max`）构建透视，支持：

- **高基数警告** — 在展开海量分类前提前提示。
- **复制 SQL** — 将透视定义导出为 SQL，便于复用或检查。
- **显示为** — 运行后可在结果区切换**原始值**、**行百分比**或**列百分比**（纯前端展示，不改 SQL）。各度量独立计算占比。若查询触达 **5000** 分组上限，占比仅相对已返回的分组。
- **列头排序** — 点击数据列头，按该列单元格值重排行（升序 / 降序 / 取消）。排序依据当前展示值（含百分比模式），不会重新查询。

## 列画像

每列的统计数据：

- 总数、**空值比例**、**去重数**、**最小/最大值**
- **高频取值**频率

## 按列统计

以**表格加柱状图**展示单列的值分布：

- **列** — 去重取值、行数，以及占**全部匹配行**的**占比**（保留两位小数，如 `12.35%`）。
- **分母** — 占比与父视图（表浏览或查询结果）的行集一致，包含当前的 **WHERE** / 结果过滤。优先复用视图已有的总行数；缺失时会额外执行一次 `COUNT(*)`。
- **上限** — 仅展示按计数排序的前 **1000** 个去重值。达到上限时会提示：占比仍相对**全部**匹配行计算，因此已展示分组的占比之和可能小于 100%；未截断时各组占比之和应约为 100%。
- **图表** — 柱状图仍使用**计数**（而非占比）。

可在表浏览与查询结果的列头菜单中打开。

## 值查看器

以**原始** / **JSON** 形式查看单元格，并提供**计算**标签页对选中单元格做统计（最小/最大/均值……），导出为 **Markdown**。
