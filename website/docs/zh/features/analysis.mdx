# 分析工具

## 透视表

通过**行维**、**列维**与**度量**（`count` / `sum` / `avg` / `min` / `max`）构建透视，支持：

- **高基数警告** — 在展开海量分类前提前提示。
- **复制 SQL** — 将透视定义导出为 SQL，便于复用或检查。

## 列画像

每列的统计数据：

- 总数、**空值比例**、**去重数**、**最小/最大值**
- **高频取值**频率

## 按列统计

以**表格加柱状图**展示单列的值分布。

## 值查看器

以**原始** / **JSON** 形式查看单元格，并提供**计算**标签页对选中单元格做统计（最小/最大/均值……），导出为 **Markdown**。
