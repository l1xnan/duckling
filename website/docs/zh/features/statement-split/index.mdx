# 当前语句执行

编辑器内可一次编写多条 SQL，通过工具栏开关选择是否**按语句分割**运行与高亮（默认**关闭**）。

## 工具栏开关

在运行按钮旁点击 **语句分割**按钮（分叉箭头图标）切换：

| 状态             | 运行（`Mod+Enter` / ▶）  | 高亮                                               |
| ---------------- | ------------------------ | -------------------------------------------------- |
| **关闭**（默认） | 执行整个编辑器内容       | 无当前语句高亮                                     |
| **开启**         | 仅执行光标所在的单条语句 | 以矩形框标出该语句（宽度随最宽行文字，非整行铺满） |

- 有**非空选区**时，始终执行选区内容（与开关无关）。
- 开关状态作用于当前编辑器标签页，刷新应用后恢复为默认关闭。

## 语句如何界定

开启分割后，系统用**分号 lexer**（忽略字符串、行注释、`#` 注释、块注释、`$tag$` 美元引号内的 `;`）结合 **tree-sitter** 辅助定位 `statement` 节点；当 tree-sitter 在复杂 SQL（中文路径、`read_parquet(...)`、WITH/CTE 等）上截断不完整时，自动回退到 lexer 结果，避免只执行半条语句。

语句之间需用 **`;`** 分隔；仅靠空行分隔的多条 SQL **不会**自动切开（仍视为一整段）。

## 示例

```sql
SELECT 1;
SELECT 2;
```

光标在第二行时点击运行 → 只执行 `SELECT 2`，并高亮该行语句。

```sql
WITH a AS (SELECT * FROM t)
SELECT * FROM a;
```

光标在外层 `SELECT` 区域时 → 高亮并执行包含 `WITH` 的完整外层语句（而非仅 CTE 内部子查询）。

## 工具栏按钮

`{}` 按钮（位于 EXPLAIN 按钮旁）扫描当前选区（无选区则全文）中的 `{{ name }}` 占位符，在 SQL 上方插入或更新 `/* @vars */` 块，缺失变量填入空值。直接在编辑器里修改值然后运行——无需弹窗。详见 [SQL 模板](/features/sql-templates/)。
