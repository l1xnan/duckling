# 设置与快捷键

## 设置套件

- **外观与语言** — 浅色 / 深色主题与显示语言（英文 / 简体中文）。
- **SSH 配置** — 可复用的 SSH 隧道配置（适用于 MySQL / PostgreSQL）。
- **键盘快捷键** — 按需重映射热键。
- **SQL 格式化** — 选择格式化引擎与选项。
- **导入/导出选项** — 连接传输行为。
- **更新** — 应用内检查更新。

## 键盘快捷键

| 快捷键               | 操作                                           |
| -------------------- | ---------------------------------------------- |
| `Mod+B`              | 切换侧边栏                                     |
| `Mod+/`              | 快捷键帮助                                     |
| `Mod+Enter`          | 运行 SQL（分割关闭：全文；分割开启：当前语句） |
| `Mod+Shift+Enter`    | 在新标签中运行 SQL                             |
| `Shift+Alt+F`        | 格式化文档                                     |
| `Mod+K` 然后 `Mod+F` | 格式化选区                                     |
| `Mod+W`              | 关闭标签                                       |
| `F2`                 | 重命名连接                                     |
| `F3`                 | 连接属性                                       |
| `F4`                 | 打开 SQL 编辑器                                |
| `F5`                 | 刷新                                           |
| `Delete`             | 删除连接                                       |

`Mod` 在 Windows / Linux 上为 `Ctrl`，在 macOS 上为 `Cmd`。所有快捷键均可在设置页重映射。
