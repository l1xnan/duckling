# 侧边栏

侧边栏（按 `Mod+B` 切换）以活动栏形式提供五个面板：

- **数据库资源管理器** — 浏览所连数据源的数据库、模式、表与列。
- **收藏** — 置顶表与已保存 SQL，一键访问，可搜索。
- **代码** — 本地 SQL 工作区文件夹与文件。
- **查询历史** — 之前运行的查询，可搜索。
- **标签页** — 按连接分组的**垂直标签页**列表。专为标签非常多的场景设计，内置按名称查找标签的搜索功能。右键标签可使用与主标签栏相同的上下文菜单（关闭、分屏、收藏等）。

## 位置

整个侧边栏（活动栏 + 面板）可停靠在**左侧**或**右侧**：

- 右键活动栏空白处，在**侧边栏位置**中选择左或右。
- 每个面板也可独立停靠：右键其活动栏按钮，选择**左**、**右**或**跟随侧边栏**。
- 左右两侧的面板可同时打开——每侧一个——各自宽度可独立拖拽调整。
- 位置与宽度会持久化，下次启动时恢复。

## 连接右键菜单

在数据库资源管理器中右键连接可：

- **重命名**（`F2`）
- **属性**（`F3`）
- **SQL 编辑器**（`F4`）
- **刷新**（`F5`）
- **导出连接**
- **上移** / **下移** — 调整连接在列表中的顺序（首项不能上移，末项不能下移）。顺序会持久化，下次启动时恢复。
- **删除**（`Delete`）
