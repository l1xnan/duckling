# 数据浏览

结果网格基于 Canvas 渲染以保证性能，支持：

- **分页** — 打开数据源（或执行未自动分页的 SQL 查询）时分页浏览数据。
- **隐藏列** — 显示或隐藏列，聚焦重要内容。
- **虚拟计算列** — 表浏览时可在工具栏添加 SQL 表达式（如 `a + 1 AS a1`），查询为 `SELECT *, … FROM table`。过滤遵循所连数据库的 SQL 规则：`SELECT` 别名在多数方言中不能用于 `WHERE`（建议写完整表达式，如 `a + 1 > 0`）；`ORDER BY` 是否可用别名视数据库而定。
- **转置** — 行列互换，从不同角度查看数据集。
- **结果过滤** — 在已加载的结果集中过滤。
- **列分析** — 在列头菜单中可打开[按列统计](/features/analysis#按列统计)、列画像或透视表。
- **单元格值查看** — 在[值查看器](/features/analysis#值查看器)中打开任意单元格，支持原始 / JSON 视图与统计。

## 复制数据

选中单元格或区域后右键，可复制为：

| 菜单项 | 输出 | 表头 |
| --- | --- | --- |
| **复制** | 纯文本（制表符分隔，与选区一致） | 随选区 |
| **复制为 CSV** / **复制为 TSV** | 逗号 / 制表符分隔 | 随选区 |
| **复制为带表头 CSV** | 逗号分隔 | 始终包含 |
| **复制为 Markdown 表格** | GFM 表格（`\|` 转义，换行转 `<br>`） | 始终包含 |
| **复制为 HTML 表格** | `<table>`（可用于文档 / 富文本编辑器） | 始终包含 |
| **复制为 JSON** | 行对象数组（列名作键） | 不适用 |

- **表头来源** — 选区包含表头行时使用真实列名；否则回退到该列的字段名，再回退到列位置（如 `col0`）。
- **取值** — 使用单元格原始值；`NULL`/空值在 CSV / TSV / Markdown / HTML 中为空，在 JSON 中为 `null`。
- **转置** — 转置视图会**还原为常规表格**后再复制：每行是原表格的一列，列名取自标签列。
- 复制超过 2000 行时会提示行数，避免误以为操作未完成。

## 值查看器

以**原始**或 **JSON** 形式查看单元格，并提供**计算**标签页，对选中单元格做统计（最小/最大/均值……）并导出为 **Markdown**——适合快速检查一组值的分布。
