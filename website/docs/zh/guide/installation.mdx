# 安装

从 [releases](https://github.com/l1xnan/Duckling/releases) 页面下载对应平台的最新安装包进行安装。

## Windows WebView2

对于 Windows 平台，如果因网络问题无法安装 WebView2，可以[离线下载安装 WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section)。

## 安装路径注意事项

软件安装路径要选择**空白文件夹**或者新建文件夹，不要选择非空文件夹，也不要将数据文件放到安装路径中。

卸载时，如果选择了清空数据文件，**整个文件夹会被删除**——即使不是软件自己的文件。

## Q&A

在 Windows 上，DuckDB 需要 [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) 包作为**运行时**依赖项。如果 DuckDB 相关功能异常，可能就是此依赖项的问题，需要自行下载安装修复。详见[《构建 DuckDB》](https://duckdb.org/docs/stable/dev/building/windows)。
