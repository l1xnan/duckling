# 本地文件

## DuckDB

直接打开 `*.duckdb` 文件。可附加**工作路径**，让查询中的相对路径保持一致解析。

## DuckDB（Quack）

通过 **URI + token** 连接 Quack 实例——内存或远程 Quack。

Quack 文件树中的目录同样支持**显示文件列表**：清单由 Quack 服务端的 `read_blob` 解析，因此路径、大小与修改时间都来自服务端，行数也在服务端统计。

## 数据文件夹

选择目录浏览 `parquet`、`csv`、`json` 等文件，无需数据库。Duckling 将文件夹作为数据源读取，便于快速探索。

在侧边栏中右键文件夹并选择**显示文件列表**，即可列出该文件夹下所有可读取文件，含路径、大小、行数与最后修改时间。大小以 `KiB` / `MiB` / `GiB` 显示，但排序按真实字节数。parquet 的行数取自文件 footer，`csv` / `tsv` / `json` 需读取文件统计，其它格式或超过 128 MiB 的文件不显示行数。打开某一行即可把该文件当作表读取。

## SQLite

打开 `.db` / `.sqlite` / `.sqlite3` 等数据库文件。
