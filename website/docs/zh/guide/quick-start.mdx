## 典型工作流

1. **打开数据源** — 选择包含 `parquet` / `csv` 文件的文件夹、`*.duckdb` 文件，或配置 SQLite / MySQL / PostgreSQL / ClickHouse 连接。
2. **浏览** — 点击浏览表、预览列、查看单元格。
3. **运行 SQL** — 按 `Mod+Enter`（或点击 ▶）执行编辑器中的查询。
4. **分析与导出** — 构建透视表、画像列、或将结果导出到文件。

`Mod` 在 Windows / Linux 上为 `Ctrl`，在 macOS 上为 `Cmd`。

更多细节参见[功能](/features/)，或直接阅读 [SQL 模板](/features/sql-templates/) 指南。
