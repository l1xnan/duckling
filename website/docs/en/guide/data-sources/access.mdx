# Access & Transfer

## File association

Opening a `.duckdb` or `.parquet` file on the OS launches Duckling directly — no need to open the app first.

## SSH tunnel

Available for **MySQL / PostgreSQL**, using **reusable SSH profiles** (configured in settings) or manual configuration.

## Connection transfer

Export **one or all connections** as JSON, optionally with secrets encrypted by a **master password**. Import the same JSON anywhere to restore your connections.
